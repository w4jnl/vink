# Tag

A monitor tag in mono on `surface-sunk`; tags drive filters, routes, maintenance windows and status-page groups.

**Provide** `label` exactly as stored (lowercase, no `#`).

**Use** at the right edge of a list row (at most three; the rest are counted in the drawer) and in the drawer header.

```html
<span class="vk-tag">prod</span>
```
