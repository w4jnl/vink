# StatusBanner

The one-line headline of a public status page: all clear, degraded, outage, or maintenance.

**Provide** `state` (`up`, `late`, `down`, `maintenance`), `text` in plain words ("All systems operational", "1 service down") and `detail` (when it was last checked).

**Use** once, at the top of the status page. Maintenance uses `accent` and the pause glyph, never a state colour.
