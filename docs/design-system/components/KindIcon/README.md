# KindIcon

A 16px monoline glyph (1.5 stroke, round caps) naming a monitor kind; drawn in `currentColor`, usually `ink-muted`.

**Provide** `kind`: `heartbeat`, `http`, `tcp`, `dns`, `tls`, `icmp`. The app ships these as an inline SVG sprite; the Icons asset group has the same drawings as files.

**Use** in list rows and the kind selector of the create form, always with a `title` or visible word nearby.
