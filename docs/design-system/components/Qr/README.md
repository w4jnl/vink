# Qr

A QR code the server renders as inline SVG, framed black on white in both themes so any phone camera reads it. The only literal colours in vink live here.

**Provide** `svg` (trusted; modules filled with `currentColor`), `label` for screen readers ("QR code for vink.w4j.nl, account j") and an optional `caption`. **Use** for two-factor setup, always next to the same secret typed out with a Copy button.
