# PingUrl

The URL a job calls, with the monitor's slug in `accent` and a Copy button beside it.

**Provide** `base` (the instance's ping base URL), the project `key` and the monitor `slug`. The field scrolls horizontally rather than wrapping.

**Use** at the top of every heartbeat monitor's drawer and in the empty state. Copy confirms by changing its own label to "Copied" for 1.4 s.
