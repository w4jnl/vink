# Notice

An inline result next to what caused it: a channel test, a created API key, a failed sign-in. Never a toast and never a modal.

**Provide** `tone` (`ok`, `error`, `warn`, `info`), a short bold `title` ("Test sent."), `text`, and optional `html` for a code line or a key with Copy. Error text from a notifier is shown verbatim in mono.

**Use** directly under the row or field it is about; it stays until the next action. `ok`, `warn` and `error` carry the up, late and down glyphs; `info` has none.
