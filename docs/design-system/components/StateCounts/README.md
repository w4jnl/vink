# StateCounts

How many monitors are in each state, as glyph and number in mono: `◆ 2  ◐ 1  ● 3`. Down and late are bold in their colour; up, paused and new stay quiet.

**Provide** counts per state; `problems: true` shows only down and late, and "all up" when there are none. With no monitors it says so.

**Use** in the project switcher (problems only), the org's project list (all states) and anywhere a project is summarised. The glyphs carry the state, so the numbers are never colour alone.
