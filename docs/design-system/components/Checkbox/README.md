# Checkbox

A native checkbox in `accent` with its label, and an optional one-line hint under the label.

**Provide** `label` (or `labelHtml`, e.g. a `StateBadge` for "send on late, down, up"), `name`, `value`, `checked`, `hint`.

**Use** inside `.vk-checks` for a set (channels on a route); for on/off settings that apply immediately use `Switch` instead.
