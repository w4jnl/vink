# Panel

A `surface` box with a heading for an inline add or edit form in a settings list. It replaces the row it edits, or sits above the list when adding, so there is never a modal.

**Provide** `title`, optional `note`, `body` (fields) and `actions`: the primary Save first, Cancel, and a destructive action last, pushed to the right.

**Use** one open panel per list. While it is open the tab's Add button is hidden.
