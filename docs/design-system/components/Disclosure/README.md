# Disclosure

A native `<details>` with a one-line summary of what is inside: the one `Advanced` section of a form, and the `As YAML` view.

**Provide** `title`, `summary` (the current values in mono, so a closed disclosure still tells the truth: "GET · retry 2× after 5s · down after 3"), `body`, `open`.

**Use** once for `Advanced` per form, after at most eight fields. Keep it open when a field inside it has an error.
